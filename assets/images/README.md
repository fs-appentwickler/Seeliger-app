# Eigene Bilder ergänzen
Die Datei protokoll-illustration.svg ist eine eigens erstellte schematische Illustration, kein Screenshot der App. favicon.svg liegt eine Ebene höher.

Echte Screenshots können hier abgelegt werden, beispielsweise pv-screenshot.webp. Personenbezogene Daten vorher entfernen. Im HTML an passender Stelle einsetzen:

<img src="assets/images/pv-screenshot.webp" alt="PV Abnahmeprotokoll: Ansicht der Projektübersicht" width="600" height="1000" loading="lazy">

Breite und Höhe an das echte Bild anpassen. Verwenden Sie eigene Bilder und komprimierte WebP/JPG-Dateien. Keine fremden Logos ohne Nutzungsrechte einsetzen.
